# TEKSHER HUB

Информационная платформа для сотрудников оператора маркировки товаров.

## Направления

- **МЗКМ – Российская Федерация:** законодательство РФ и материалы внешнего контура маркировки.
- **ГАИС МТ – Кыргызская Республика:** законодательство КР и внутренний контур национальной системы.
- **ЕАЭС:** наднациональные документы и применимые правила взаимодействия.

## Технологии

- React
- Vite
- Lucide React
- CSS

## Запуск локально

Требуется Node.js.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Сборка создаётся в каталоге `dist`.

## Публикация на Netlify

- Build command: `npm run build`
- Publish directory: `dist`

Файл `public/_redirects` обеспечивает fallback для клиентской навигации.

## Текущее состояние

Версия 0.1 – интерфейс-прототип. Список документов содержит демонстрационные записи, не являющиеся официальной нормативной базой. Backend, база данных, авторизация, загрузка файлов и автоматическое получение нормативных актов ещё не подключены.

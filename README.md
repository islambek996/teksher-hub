# TEKSHER HUB

Информационная платформа для сотрудников оператора маркировки товаров.

## Направления

- **МЗКМ – Российская Федерация:** законодательство РФ и материалы внешнего контура маркировки.
- **ГАИС МТ – Кыргызская Республика:** законодательство КР и внутренний контур национальной системы.
- **ЕАЭС:** наднациональные документы и применимые правила взаимодействия.

## Технологии

- React
- Vite
- Lucide React
- CSS

## Возможности интерфейса v0.2

- Навигация по юрисдикциям и каталогу.
- Поиск по названию, описанию, тематической области и номеру документа.
- Фильтры по типу материала и статусу карточки.
- Форма добавления карточки документа с реквизитами, датой и ссылкой на официальный источник.
- Страница подробностей с метаданными и переходом к источнику.
- Пользовательские карточки сохраняются в `localStorage` текущего браузера.

## Важно: текущие ограничения

- Демонстрационные записи – это заглушки интерфейса, не официальные нормативные документы.
- Пользовательские карточки доступны только в браузере, где их добавили. Они не синхронизируются между сотрудниками и устройствами.
- Файлы пока не загружаются и не хранятся на сервере.
- Backend, база данных, авторизация, история редакций, контроль срока действия документов и автоматический мониторинг официальных источников ещё не подключены.
- Ссылка на документ проверяется на использование протокола HTTP или HTTPS; её содержание и юридическая актуальность требуют ручной проверки перед использованием.

## Запуск локально

Требуется Node.js.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Сборка создаётся в каталоге `dist`.

## Публикация на Netlify

- Build command: `npm run build`
- Publish directory: `dist`

Файл `public/_redirects` обеспечивает fallback для клиентской навигации.
